# Quant Momentum Research

## Research Question

Does six-month cross-sectional stock momentum predict subsequent one-month returns among U.S. large-cap stocks?

## Hypothesis

Stocks with higher returns over the previous six months will, on average, have higher returns during the following month.

## Goal

Investigate the relationship between past stock performance and subsequent returns using historical market data, statistical analysis, and backtesting.
